# Security Policy

## Supported Versions

The following versions of the Forensic Engine are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of this forensic tool seriously. If you discover a vulnerability that could lead to code execution via a malformed PE file or a bypass of detection logic, please follow these steps:

1. **Do not** open a public issue.
2. Email the maintainer at `adrian.obungu@example.com` (Replace with your actual contact or use GitHub's private reporting).
3. Provide a sample (if safe) and a description of the exploit vector.

We aim to acknowledge all reports within 48 hours and provide a fix or mitigation within 7 days.
